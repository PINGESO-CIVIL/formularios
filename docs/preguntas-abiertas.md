## Pendiente del documento de componentes (DAS §1, §2, §4 y Hito 1)

Una vez incorporado el documento de componentes de la sección Civil en
`docs/referencia/`, verificar y actualizar los siguientes artefactos:

- [ ] **Nombre oficial del servicio (`<servicio>`)**: alinear nombre del repo en `PINGESO-CIVIL`, módulo Go (`apps/api/go.mod`), paquete npm (`@pingeso-civil/<servicio>-ui`), `sonar.projectKey`, `name:` de `docker-compose.yaml` y nombres de imágenes GHCR.
- [ ] **Número `N` y puertos locales**: confirmar `51N0` (web) y `51N1` (api) en `docker-compose.yaml`, `README.md` y variables de entorno.
- [ ] **Mapa de dependencias (proveedores y consumidores)**: confirmar dependencias acíclicas, copiar cada contrato proveedor a `contracts/externos/<servicio>.yaml`, generar clientes y publicar `contracts/openapi.yaml` a los grupos consumidores.
- [ ] **Protocolo de integración**: confirmar si existe mensajería asíncrona obligatoria o si el servicio queda estrictamente en REST síncrono (DAS §2).
- [ ] **Mocks oficiales de Hito 1**: verificar que los datos simulados de la API y los mocks de consumo (`prism mock` / MSW) cubren todo lo exigido para el Hito 1.
